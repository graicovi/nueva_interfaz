# Nueva interfaz Jobbox

Prototipos HTML de la interfaz Jobbox construidos con los estilos y recursos visuales compartidos del proyecto.

## Pantallas

- [0template1.html](./0template1.html)
- [0template2.html](./0template2.html)

## Recursos compartidos

- `jobbox_fuente_original.css`: CSS de referencia proporcionado para la aplicación.
- `jobbox_templates.css`: composición y adaptación visual de los prototipos.
- `jobbox-icons.svg`: biblioteca SVG monolineal utilizada mediante referencias externas.
- `jobbox-logo.svg`: logotipo vectorial oficial adaptado a la variante violeta/tinta para fondos claros.
- `jobbox-logo.png`: respaldo rasterizado del logotipo anterior.

Los HTML y sus recursos deben servirse mediante HTTP/HTTPS. Abrirlos directamente con `file://` puede impedir que algunos navegadores carguen símbolos SVG externos.
